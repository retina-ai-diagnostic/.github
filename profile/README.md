# 👁️ Eye Diagnostic System

Система диагностики глазных заболеваний с использованием нейросетей.  
Анализ снимков глазного дна с помощью искусственного интеллекта.

---

## 📦 Репозитории проекта

| Репозиторий | Описание | Технологии |
|------------|----------|------------|
| [frontend](https://github.com/retina-ai-diagnostic/frontend) | Веб-интерфейс для загрузки и просмотра результатов | Next.js, TypeScript, Tailwind |
| [backend](https://github.com/retina-ai-diagnostic/backend) | API сервер для обработки запросов | NestJS, PostgreSQL |
| [ai-service](https://github.com/retina-ai-diagnostic/ai-service) | Нейросеть для диагностики | FastAPI, PyTorch |

---

## 🚀 Быстрый старт

```bash
# Клонируйте все репозитории
git clone https://github.com/retina-ai-diagnostic/frontend
git clone https://github.com/retina-ai-diagnostic/backend
git clone https://github.com/retina-ai-diagnostic/ai-service

# Запуск через Docker Compose (скоро)
# docker-compose up
```
